Kundai Farai Sachikonye · for Mark Doerr

Modelling means drawing a boundary,
and a boundary is never free.

That one sentence, taken seriously, produces a solvent that is a vertex rather than an attribute, a reaction direction that belongs to the medium rather than to the reaction, a causal graph that is computed rather than curated, and a runtime in which the graph that models the chemistry is the same object that runs the experiment.

This page is the map. Each idea below has its own page with the argument stated plainly, an interactive figure you can push on, and a note saying exactly what is proved, what is measured, and what is still open. Follow whichever thread interests you — they are independent, and none of them requires the others to be read first.

The through-line

Individuation has a cost that never reaches zero. Everything else in this framework is a consequence of taking that seriously in one domain or another — chemistry, instruments, computation.

The ideas

00

S-entropy

Where the rest comes from: distance to truth measured from a stated observer. The foundation — including where its own derivation fails.

 01

Individuation

A part is fixed as the complement of everything it is not. Put the surroundings in the graph as a vertex, and identity becomes a minimum cut.

 02

The floor

No finite observer separates anything at zero cost. The same statement covers a bounded knower and a plate reader with 4001 outputs.

 03

Propagation

For a system with a dynamical description the causal graph is already there: edges are recovered, not asserted. One map, two arguments.

 04

Path opacity

Only endpoints are checked, so interiors are free. That is where the speed comes from — and why mechanism is not recoverable from endpoint data.

 05

The languages

Four domain languages over one semantics, and a converter that records whether the source stated a fact or the toolkit supplied it.

 06

The graph as runtime

A node is a subtask fused with the code that realises it. An edge exists because a value propagated. The runtime judges nothing.

What this means for LARA

Ontology, reasoner, query layer, scheduler and provenance store as one object addressed at different depths. The layer mapping, stated concretely.

That was found by the validation, reported against interest, and turned into a usage rule rather than quietly dropped. It is on this table for the same reason it is in the paper.

Where the implementation lives

None of this is a proposal for work to be done. The runtime is implemented, four domain-specific languages compile and execute against it, and the cytochrome P450 monograph takes the framework through one enzyme family across roughly twenty papers. The runtime page describes what actually runs and what does not.

Every page states its own limits. Where a number here disagrees with a number in a paper, the validation output is the authority and the disagreement is noted on the page rather than reconciled silently.
