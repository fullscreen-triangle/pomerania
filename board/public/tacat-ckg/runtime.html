05 · The graph as runtime

The graph that models the chemistry is the thing that runs the experiment.

A conventional runtime executes a program: an ordered sequence whose control flow is knowable in advance and whose termination is a verdict. This one discards all three commitments. The unit of work is a node — a subtask fused with the code that realises it. Modules read values, transform them internally, and emit new ones. An edge exists because a value actually propagated along it.

The consequence that matters

Edges are a product of a run, not an input to it. The nodes are the durable objects — what can be computed, catalogued and imported. The trajectory is what was computed, and it cannot be stored as a schedule because it does not exist until the run produces it.

The runtime judges nothing

There is no exit code, and the reason is structural rather than stylistic. An exit code is a verdict, and to issue one the issuer must compare an achieved state against an expected one. The runtime holds no expectation. It executes every chunk bundled on a node and reports what happened.

Conventional runtimeThis runtime
Exit code: success or a taxonomy of failure No verdict — meaning belongs to the consumer
An exception halts the process An exception becomes a value on the node; the run continues
Same inputs must give the same output Runs are not expected to be bit-identical
Control flow is a plan fixed before the first instruction The trajectory is the set of nodes across which information propagated
Reproducibility is a property of the result Reproducibility is relocated to the protocol
Why this is right for laboratory work

This is the correct model for computation organised as experiment rather than as procedure. Results are meaningful only to their consumers. Runs are not expected to be bit-identical, because instruments are not. Anomalies are recorded rather than raised. And what should be reproducible is the protocol, not the number that came out of it.

Reproducibility as a fingerprint of the protocol

The provenance fingerprint hashes the subtask identity, the sorted chunk names and the edits — and deliberately excludes the values. Two runs of the same protocol that produce different measurements have the same fingerprint. Two runs that produce the same number by different protocols do not.

Resolution: one computation, addressable at any depth

Nodes carry hierarchical addresses, so the same computation can be expressed coarsely — import a standard setup and touch nothing — or with step-by-step control. Editing at depth k touches exactly the subtree under that prefix and nothing else.

That is what lets different experts work at different depths in different regions while the whole remains one addressable object: a chemist wants one knob, a method developer wants every knob, and today those are different tools.

What actually runs

This is implemented, not proposed. Four domain-specific languages compile and execute against the runtime, each with a real tokenizer, parser and evaluator rather than a configuration format:

LanguageWhat it expressesBackend
.sbsCircuits, nodes, edges, perturbations over a network Compiles to GLSL; solves on the GPU, with a CPU fallback
.hjAccountability — what a claim rests on Lexer, parser, accountability pass, exact interpreter
.ssInstrument acquisition and staged analysis Compiles a stage, executes it against a capability layer
.grfOrchestration across modules Own parser, typechecker, interpreter

The composition mechanism is one line: a module's output is keyed fact:<module>#<chunk>, so several modules can write different facts to the same node without collision. That is what lets one catalytic state simultaneously hold reaction chemistry, a circuit result and a spectroscopic acquisition.

What does not run. The composition described above runs in the terminal today; it is not yet wired into the browser page that shows the four languages side by side. The tabs there demonstrate each language independently on its own subject matter — an electron-transport circuit, an accountability example, a tryptic digest — rather than jointly on one catalytic cycle. Saying so is cheaper than being caught by it.
