03 · Propagation

The causal graph is already there. You do not have to assert it.

A causal knowledge graph over a biochemical network is normally built by asserting edges: a curator reads a paper, a text-mining pipeline extracts a relation, a statistical test rejects a null. The graph becomes a database of claims, and its quality is the quality of its claims. For a system that admits a steady-state description, none of that is necessary — the graph is the fixed point of a propagation the system already defines, and its edges are recovered rather than recorded.

A metabolic network at steady state is a circuit

The correspondence is exact, not a metaphor. Chemical potentials μᵢ = μᵢ° + RT ln cᵢ are node voltages. Conductances Gᵢⱼ = kᵢⱼcᵢ/RT are edge admittances. Fluxes Jᵢⱼ = Gᵢⱼ(μᵢ − μⱼ) are branch currents. Kirchhoff's current law holds exactly when mass is conserved, and the voltage law is the Wegscheider condition.

The step a chemist will press on first. That flux law is neither mass-action nor Michaelis–Menten. It is a near-equilibrium linearisation, and kcat is being used as a first-order constant with no enzyme concentration and no KM. Where the network sits far from equilibrium the correspondence degrades, and nothing here establishes how fast. This is the assumption to attack.

One map, two arguments

The identification

The propagation operator that carries a marking through the network is the same map whether the system is at rest or driven. Evaluated at the trivial process it is a graph; evaluated at a driven process it is a propagation. The circuit and the graph are not two objects. There is no translation step to get wrong, and no synchronisation problem between a stored graph and a live model — because there is no stored graph.

This is the point that matters for infrastructure rather than for chemistry. A curated graph and a running model drift apart, and keeping them aligned is permanent work. If the graph is the model at a particular argument, the drift cannot occur.

Where this failed, and what the failure taught

Each species is assigned a point in a three-axis coordinate — throughput, capacity, potential — each normalised by a network extremum. On glycolysis, the citric acid cycle and EGFR–MAPK the three axes carry independent information. On oxidative phosphorylation they do not.

What was done about it

The result was not dropped and the normalisation was not quietly changed. It became a named limitation with a usage rule: compute the axis regressions per network, and distrust the address wherever one axis is recoverable from the others. A rank or logarithmic normalisation would probably behave better; that has not been established, so it is not used.

What a reasoner buys, measured

A companion measurement is worth stating because it cuts against the framework's own interest. Over the full approved reaction set, plain SPARQL against a public endpoint and a description-logic reasoner return the identical 75 reactions — the reasoner derives nothing a four-way join could not.

Break-even is about four queries. But the honest reading is sharper than “the reasoner is unnecessary”: the defining pattern uses only existentials, subsumption and a value restriction, which is the first-order-rewritable fragment. The ontology is doing query-shaped work on a description-logic engine. That points at an ontology-based data access system, not at abandoning the ontology.

And the qualification that guts it further. The loader asserted the class memberships, so neither engine did the taxonomic work. The reasoning was performed by hand and cached as five constants — a cache with no invalidation, which goes stale silently if the source ontology reorganises. Where a reasoner genuinely cannot be replaced by a query: reachability over a derived edge, consistency, class-level subsumption, and closure through existential restrictions.
