04 · Path opacity

If only the endpoint is checked, the interior is free.

Two routes with the same input and the same output are indistinguishable to any invariant computed at the endpoints. That is nearly a tautology, and it has two consequences pointing in opposite directions: it is where the speed comes from, and it is a hard limit on what endpoint-characterised data can tell you about mechanism. Both matter, and the second is the one a scientist should hear first.

The snow

If we wake up to find snow outside, and I claim that it came from space, it does not change the fact that there is snow outside.

The proposal is not refuted by the local implausibility of the step. It is refuted only if no route containing that step reaches the snow. There are two separate questions here — is there snow, settled by looking, and where did it come from, which is a different question whose answer does not retroact on the first. A locally impossible intermediate is admissible exactly when some completion through it reaches the observed output.

Why the triviality is the point

The proof that substituting an intermediate leaves the endpoint alone is three lines, and that is not a weakness. The endpoint check is what carries the weight, so the substitution argument should be short. A long proof there would mean the intermediates were load-bearing — which is exactly what the principle denies.

The consequence a scientist should hear first

An edge in a recovered causal graph names an equivalence class of mechanisms, not a mechanism. That is not a defect of this construction — it is a theorem about what endpoint data determines, and it applies to any provenance record that stores only inputs and outputs.

Stated for a catalysis audience

You have inlet and outlet composition. Mechanism is not recoverable from them, and no increase in the precision of either recovers it. Every schema that records only endpoints is provably mechanism-blind. If the route is the scientific object — mechanistic enzymology, isotope tracing — this is the wrong instrument, and increasing resolution does not help.

Measured on four real pathways, the opacity rate is 1.0 across 290 multi-path pairs: no endpoint-computed invariant separated any two routes, on any network, ever. The interiors genuinely differ — up to 13 distinct interior paths between one pair of endpoints — so the setup is not empty. The conclusion is just analytic once the invariant is a function of the endpoints.

The other direction: interiors that leave the physical domain

If the interior is unconstrained, an intermediate need not be physically realisable. A coordinate may be decomposed into components that average to a physical point while individually lying outside the admissible range. These are the virtual intermediates, and the claim is that they are where the speedup lives: restrict a backward completion to physically realisable intermediates and the cost returns to linear.

This one is a conjecture and is labelled as such. The claim that admitting virtual intermediates is what converts linear cost into logarithmic has an asserted step: that locating a physically realisable decomposition requires examining a number of cells that grows with the space. That has not been proved, and the validation reports the physical-to-virtual operation ratio falling rather than growing. Presented here as a mechanism with a plausible story, not as a result.

The open question, stated precisely

The unconditional version of the principle is false, and it should be said plainly: garbage intermediates usually do break things. What makes the snow argument work is that the snow was established by looking — a check that does not route through the origin story and is independently sound. That independence is the hypothesis, and writing it down is the work that remains.

The theorem this framework needs and does not yet have

Given a verifier V that accepts on endpoint data alone, and a claim C the endpoint is supposed to certify, state the conditions on (V, C) under which V's acceptance implies C irrespective of the interior — and exhibit a class where it does not. That is the difference between analytic continuation through complex intermediates being legitimate, which it is, and any route being fine, which it is not.

The lineage this belongs to

The idea is not eccentric and has a long pedigree, which is worth naming because it changes how the claim should be read.
