Five layers you keep in sync are one object addressed at five depths.

A laboratory pipeline that controls instruments and robots already has all the pieces of this framework, held apart. An ontology models. A reasoner infers. A query layer retrieves. A scheduler plans. A provenance store records what happened. Each carries its own representation of the same experiment, and keeping them aligned is permanent, unrewarding work.

The proposal

They are not five things that must agree. They are one graph, read at different depths and at different arguments. The drift cannot occur because there is nothing to drift between.

The mapping, stated concretely

Your layerBecomesWhy that is the same thing
Ontology model Node identity plus its bundle of realisations A class is a subtask name; an instance is a node carrying values
Reasoner Federation dispatch across modules Inference is a module reading values and emitting new ones
SPARQL / query access Walking the graph the run produced The store is what was emitted, with a closed retrieval vocabulary
Workflow scheduler The trajectory Emergent rather than planned — the set of nodes information crossed
Provenance store The edges themselves An edge exists because a value propagated; provenance is not a parallel record but the graph's own structure
Instrument driver Node execution, with the monitor's floor attached What the instrument entitles the node to assert is computable from its specification
Honest about the standards. This is a proposal about executable knowledge graphs, and it does not yet speak RDF, OWL, SHACL or PROV natively. The static reading is an ordinary knowledge graph and can be expressed in those terms; the contribution is the dynamic reading layered on it. In particular the audit record maps onto PROV directly — activity, used, wasDerivedFrom — and that mapping is a paragraph of work rather than a research problem. It has not been done.

Three things it changes on the bench

1 · Reproducibility moves to the protocol

Two runs of one assay do not produce the same number, and treating that as a bug produces pipelines that lie. Fingerprinting the protocol rather than the result gives a reproducibility claim that is true: this is the same experiment, without asserting this is the same measurement. How the fingerprint is built →

2 · Anomalies stop halting runs

A chunk that raises deposits an error value on its node and the run continues. Nothing upstream is lost because something downstream failed, and the failure is in the record rather than in a log file beside it. Against a halt-on-error comparator this is the difference between reaching every node and reaching the first anomaly.

3 · Instrument limits become part of the model

What a monitor entitles you to conclude is computable from its specification, so the floor is not a footnote in a methods section — it sits in the graph beside the value. Two consequences a bench will feel: a ranking finer than the cell width is a ranking of quantiser codes, and a triplicate protects against a dead instrument but not against a drifting one. Where the chemistry actually enters

The framework was taken through cytochrome P450 across roughly twenty papers, and the resulting catalytic-cycle graph is where the composition shows: one node holds reaction chemistry, a circuit result and a spectroscopic acquisition simultaneously, contributed by three different modules.

Every page in this presentation states what is proved, what is measured, what is conjecture, and what has been refuted — including results that went against the framework's own interest. Those are on the pages rather than in an appendix because they are the part of the work that would not survive a tidy-up, and they are the reason the rest should be taken seriously.
