1. What this is, and what it is not

It is not

Part of the submission. The tacat repository froze on 28 July 2026 and contains none of this.

A claim that the built thing is inadequate. Every gap discussed here is one the project's own GAPS and RATIONALE documents found first, and recorded against themselves.

A substitute for the five brief steps. JOB_PROFILE.md §1 is explicit that the stated technology surface is a closed list; this is strictly additional and belongs after it, never instead of it.

It is

An answer to the question RATIONALE.md §6 says is the real target: does the candidate know where the model stops?

Four costed proposals, ordered by value per hour, with the weakest one explicitly withdrawn for this scale in Chapter 5 §2.

Written so that the strongest objection to it appears in it — Chapter 5 §3 states the case against the whole approach as forcefully as I can.

Chapter 1 records G10: three gates green over a graph in which every external identifier was fabricated, because all three were asking variants of one question. 3. The single thread

All four proposals are the same move, and it is worth naming because it is the only idea here:

The move

Every check in the submission today compares the graph against something inside the graph — a label against the row that generated it, a PURL against a shape, a test suite against the questions someone thought to write. Those checks are necessary and they are all blind in the same direction. Each proposal below replaces one such check with a comparison against something the project does not own: an external authority, an unconsulted source, a distinction the vocabulary cannot draw.

That is what the floor theorem says, in one sentence: a thing is individuated only against what it is not, so a check that never leaves the thing cannot individuate it. Whether you reach that conclusion from the theorem or from the G10 corruption run is immaterial to the code — and the code is what is being graded.
