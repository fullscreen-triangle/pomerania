Chapter 4

Where the model stops

RATIONALE.md §6 says the real thing being graded is whether the candidate knows where the model stops. OUT_OF_SCOPE_QUESTIONS answers that by listing what the ontology cannot do. This chapter proposes making the boundary derivable rather than enumerated — so that it holds for questions nobody has thought of yet.

★★★ the stated target 13 min RATIONALE §6.3 · OUT_OF_SCOPE his own paper's subject
Provenance. This chapter rests on unpublished single-author work (The Irreducible Boundary of a Bounded Resolvable Space, §6; Contact Graphs, T8). It has not been peer-reviewed. The detectability criterion below is stated in measure-theoretic terms in the source; the translation to "what a fixed vocabulary can express" is an analogy I am drawing, not a theorem in the paper. It is offered because it is productive, and flagged because it is the weakest inferential step in these five chapters.

1. What the repository does now

queries/competency.py carries OUT_OF_SCOPE_QUESTIONS — competency questions from NFDI4Cat's own set that the ontology deliberately cannot answer, each with what it would take:

QuestionRecorded blocker
Kinetic parameters — Km, kcatNeeds quantities with units: QUDT vs OM-2 vs EMMO
Purification protocolNeeds a laboratory-process model
ImmobilisationNeeds materials and a process model
Assay conditionsNeeds experiment, device, measurement classes

This is already the right instinct, and it is unusual — most submissions list what they built. But it is an enumeration, and enumerations have a specific weakness: they answer "can it do X?" only for the X someone thought to write down. Ask a question not on the list and the honest answer is a shrug.

The failure mode of an enumerated boundary

An enumerated boundary looks complete from inside. There is no way to tell, from the list, whether the list is exhaustive — which is the same structural problem as a green test suite in Chapter 2. A boundary you can derive answers for questions nobody enumerated.

2. Detectability

The bounded-space paper asks when a region is distinguishable at all by an agent with finite resolution. Its answer is a ratio, not a size:

Thm · Detectability Irreducible Boundary, Thm 6.3

A region is distinguishable if and only if its own scale exceeds its boundary thickness. Below that, it is engulfed by its own separator: every part of it also borders something else, so nothing of it stands clear.

The inversion that makes it useful

Smallness is never the cause of silence. A thing fails to register because its boundary is thick relative to it — the distinctions you would need to draw to mark it off are coarser than the thing itself. Translate to vocabulary: a question is unanswerable not because it is "advanced" but because the distinctions it requires are finer than any the vocabulary draws.

That gives a mechanical test, and it is one a person can apply in a presentation without any of the theory: name the finest distinction the question turns on, then ask whether the vocabulary has a term that makes exactly that distinction. If not, the question is engulfed — and the answer to "can it do X?" is not "no", it is "no, and here is the specific term that is missing".

Why the buffer row is the interesting one

It is the closest miss, and it shows the criterion doing real work. tacat does have a role concept — ParticipantRole — and it does already model one non-participant correctly: PLP is domained on the enzyme as hasCofactor, deliberately not on the reaction. So the vocabulary has the shape of the distinction "present but not consumed". What it lacks is one more term. That makes the buffer question the cheapest of the four to reach, and the detectability test is what surfaces that ordering — an enumeration lists all four as equally out.

3. The bound on authorship

There is a second result worth having in a presentation, because it answers a question that gets asked of every ontology: why does your model not cover everything?

Thm · Floor-limited authorship Contact Graphs, Thm 9.9 (T8, Bound III)

An author who specifies a structure using distinctions of resolution β can express only distinctions of cost ≥ β. Any finer distinction present in the thing modelled is below the author's resolution — present in the world, absent from the specification, and not through carelessness.

The paper's phrase for it is doors, not rooms: an author lays down the boundaries at their own resolution; whatever is finer belongs to the thing itself. For an ontology this is not a limitation to apologise for — it is what a vocabulary is. A term makes exactly one distinction, and everything finer than that term is inside it, undifferentiated.

Usual framing

"The model is incomplete; with more time we would add kinetics, process, materials."

Invites the question how much more would be enough, which has no answer, and implies completeness is reachable.

Floor framing

"The model resolves to the level of which species participates in which role. Anything finer is inside a term, by construction."

States a resolution, which is checkable, and predicts which questions fail before anyone asks them.

4. What this proposes building

4.1 Out-of-scope questions get a stated resolution

Each entry gains one field: the distinction the question needs, and the term that would carry it. This turns a list of gaps into a specification of the next increment.

4.2 A test that the boundary is where it is claimed to be

The listed questions are asserted to be unanswerable. Nothing checks that. If a later change made one of them answerable, the list would silently become wrong — the same failure shape as everything in RATIONALE.md §4.

Why this is the single highest-value item in the five chapters

RATIONALE.md §6 is explicit: the third differentiator — "does the candidate know where the model stops?" — is "the real target. It is the subject of his own paper, it is the explicit agenda for the presentation." A test that guards the stated boundary is the strongest possible form of the answer, because it converts the claim from something asserted in a document into something the pipeline would notice becoming false.

5. What this does not fix

Be able to say this out loud
  • The detectability analogy is mine, not the paper's. Thm 6.3 is about regions in a measure space with a finite partition. Reading "boundary thickness" as "the coarsest distinction the vocabulary draws" is an interpretation. It is productive and it generates the ordering in §2.1, which an enumeration does not — but if challenged, concede it immediately and fall back on the table, which stands as ordinary analysis without any theorem.
  • "Finest distinction the question turns on" is a judgement call. Two people can analyse the same question differently. The value is that the disagreement becomes explicit and arguable, not that the method is mechanical.
  • The boundary test is easy to write badly. Asserting a term's absence is a weak check — the term could be added under a different name and the test would still pass. It guards against the obvious regression, not against a determined one.
  • None of this makes the out-of-scope questions answerable. Kinetics still needs a unit vocabulary, and choosing between QUDT, OM-2 and EMMO is a real decision with real consequences that this chapter does not make.
