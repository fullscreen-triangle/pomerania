1. The premise

The thing that makes this project defensible is enzymology, and you have that already.

Most people who could write the code could not have told you that pyridoxal 5′-phosphate must not be a reaction participant, or that "L-cysteine" as a bare name lands on the wrong tautomer. Those are the decisions being graded.

What you need from this primer is the vocabulary and the mechanics to explain how those chemical decisions were encoded. That is a much smaller thing to learn than a computer-science degree, and this is scoped to exactly it.

The one-sentence framing

I treated the requested demo application as a miniature FAIR data product. Everything else — reusing ChEBI identifiers rather than inventing your own, running a reasoner, the validation gates, the federated query — is a consequence of that sentence rather than a list of features.

If you remember one line, remember that one, and let every part of the system be an answer to "why would a data product need this?"

2. What was actually built

A small service. You give it a question in a query language; it answers from a graph of facts about three transaminase reactions.

Underneath, six things happen in order — and each one proves something about the one before it. That chain is the whole design.

1

Verified reference data

Nine chemical entities, three EC numbers, three Rhea IDs, seven UniProt accessions — each checked by hand against the primary database.

→ the facts are real, and traceable
2

An ontology

A formal description of what a reaction is — its parts, and the roles they play — written in OWL, a logic a machine can compute over.

→ the vocabulary is coherent, and can classify
3

A knowledge graph, reasoned over

The data in that vocabulary. Then a logic engine reads it and derives conclusions nobody wrote down.

→ the ontology does work rather than decorating
4

Validation and tests

SHACL shapes reject malformed data. Real scientific questions run as automated tests on every change.

→ the graph answers what it claims to
5

A SPARQL endpoint

A web service implementing a published standard, so off-the-shelf tools query it with no modification.

→ the data is reachable by someone who isn't you
6

A container, built automatically

The whole thing frozen into one runnable image, rebuilt from scratch by a server on every change, with all the gates above running first.

→ the result reproduces away from your laptop
You already know this shape

It is a protocol with controls at every step. Reagents verified against a certificate of analysis, method written down, positive and negative controls alongside, results checked against acceptance criteria, the whole thing repeated by someone else.

Nobody would accept a result from a protocol missing those. Computing calls the same discipline "reproducible builds" and "continuous integration".

3. The three ideas that carry the weight

IdeaIn one lineWhere
Necessary vs sufficient The reactions are never labelled "transamination" — a logic engine works it out. That is the difference between a knowledge graph and a database. Ch. 2
Roles, not molecules Substrate and product are roles in a direction, not properties of a molecule. Encoding that needs a bridge node. Ch. 2, 7
Reuse identity Every chemical points at its real ChEBI identifier — as a link, not text. That is what makes the federated query possible at all. Ch. 1, 3

4. The thread through everything: silent failure

One property of this domain is worth internalising before any technical detail, because it explains why the project looks over-engineered in places.

Almost every mistake available here produces no error message.

200 OK…and the status it returns it with
✓ greenwhat the test suite says
The bench equivalent

A Western blot with no bands. Is the protein absent, or did the secondary antibody never go in? The blot cannot tell you — which is why you run a loading control. Not because you expect it to fail, but because without it "no signal" has two readings you cannot distinguish.

Every seemingly excessive gate in this project is a loading control. The SHACL shapes, the assertion that the reasoner actually fired, the negative-control reaction, the test that checks an identifier is a link and not a string — each exists because the corresponding failure is invisible.
