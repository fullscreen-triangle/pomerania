The frame

I treated the requested demo application as a miniature FAIR data product. Everything else — reusing ChEBI identifiers, running a reasoner, the validation gates, the federated query — is a consequence of that sentence, not a feature list. Say it in the first thirty seconds and let every later answer hang off it.

1 · Facts as data

Every fact is a triple: subject, predicate, object. Every name is an IRI — a URL used as a name — so two datasets that use the same IRI are provably talking about the same thing, with no mapping table. That is the whole reason for RDF. The distinction that broke v0: an identifier stored as a string looks identical to one stored as a link, and joins to zero rows without erroring.

2 · Meaning & inference

TransaminationReaction is a defined class — necessary and sufficient conditions — written over chemical classes and participant roles, never over specific molecules. No reaction is asserted to be one; HermiT derives all three at build time. The negative control is glutamate dehydrogenase: it contains both headline molecules with the roles reversed, and is correctly not derived, because the definition discriminates on role rather than molecular presence.

→ Chapter 2 · the one that matters most

3 · Asking questions

SPARQL is pattern-matching over triples. The competency questions are the test suite — CQ01–CQ04 quoted verbatim from NFDI4Cat's own biocatalysis set. The pair that justifies the model: CQ05 returns 4 reactions that have L-glutamate, CQ06 returns 3 that produce it, and they differ by one line — a filter on the participant's role. The federated query joins the local graph to live UniProt on shared Rhea identifiers.

→ Chapter 3

4 · Checking the data

OWL infers under an open world; SHACL validates under a closed one. They are not alternatives. The demonstrating case: cardinality of one with two licences asserted — the OWL reasoner does not complain, it infers owl:sameAs and silently declares CC-BY and CC0 identical; SHACL reports a violation. Same data, opposite outcome.

→ Chapter 4

5 · Serving it

It implements the read subset of the SPARQL 1.1 protocol rather than a bespoke endpoint, so stock clients work unmodified. Malformed queries return 400, not 500. SERVICE clauses are refused — federation is something done at build time, not something an anonymous caller does through your server.

→ Chapter 5

6 · Shipping it

The reasoner runs at image-build time: the builder installs a JVM and runs HermiT; the runtime stage ships no Java at all. If reasoning fails, the image does not build. CI runs code gates, then data gates — including an assertion that the inference actually fires — and only then builds the image, tagged by commit SHA.

→ Chapter 6

7 · The chemistry

PLP hangs off the enzyme, not the reaction — a prosthetic group cycling PLP→PMP→PLP on an active-site lysine, which is why Rhea's equations have four participants and UniProt calls it a COFACTOR on the protein. Modelling it as a fourth substrate would validate perfectly and be chemically false. And substrate/product is a role in a direction: E. coli AlaA carries the same Rhea master as human ALT1 but runs right-to-left, consuming the glutamate ALT1 produces.

→ Chapter 7

8 · The thread through all of it

Almost every mistake available here produces no error message. Wrong ChEBI microspecies → zero rows, no error. Identifier as a string → the same. A defined class that classifies nothing → passes a consistency check. A typo in a shapes file → constrains nothing. Every gate in the project that looks excessive is a loading control for an invisible failure.

9 · Where it stops

The graph cannot answer kinetics (needs quantities with units), organism of production (needs the federation or an organism model), or purification and engineering (needs a laboratory-process model — LARA's actual domain). Those are recorded in OUT_OF_SCOPE_QUESTIONS, with what each would require. Knowing where a model stops is the point of writing competency questions at all — and the assessor published a paper on exactly those limits.

The governing rule

Any line you cannot explain is a liability, not an asset. "I don't know — here is how I would find out" costs far less than a confident wrong answer given to someone who has published on the topic.
