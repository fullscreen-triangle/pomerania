3. Running it

cd nfdi4cat-v1

uv sync --all-groups           # create the environment
tacat build             # run HermiT, write data/reactions.ttl   (needs a JVM)
tacat infer             # print what the reasoner derived        (needs a JVM)
tacat questions         # print the competency questions
tacat query "SELECT ..."  # one query against the built graph
tacat federate          # join the graph to live Rhea/UniProt   (needs network)
uv run pytest                  # 182 tests; 3 network tests deselected by default
tacat serve             # http://localhost:8000

docker compose up --build      # reasoning happens in the build stage

Two things to know before the first run. build and infer need a JVM on PATH, because Owlready2 runs HermiT as a subprocess. serve does not, provided data/reactions.ttl exists — on a clean checkout it falls back to building in-process and does then need one, and it says so in the log before trying.

4. What was open, and what is left

G1–G8 are all closed. They are kept here rather than deleted because the shape of each fix is more interesting than the fix, and because a reviewer who read an earlier draft will ask. Full detail in docs/GAPS_0.md and docs/GAPS_1.md.

G1 Reproducibility is now guarded. The reproducible-build job builds twice and compares bytes; tests/test_reproducibility.py asserts the same property, plus the weaker isomorphism form closed
G2 Read-only is a policy. api/policy.py refuses update forms and SERVICE by form rather than by accident of rdflib’s parser; tests/test_policy.py covers it closed

5. Glossary

A-BoxThe instance data of an ontology — individuals and their facts. Your rows.
ALT / ASTAlanine and aspartate transaminase. Two of the three enzymes here, and the standard liver-function markers on a blood panel.
amino group−NH2. The thing a transaminase moves from one molecule to another.
bridge nodeAn intermediate node that carries the attributes of a relationship, because RDF edges cannot. A join table with columns.
ChEBIChemical Entities of Biological Interest. The identifier authority for molecules.
cofactorA non-protein molecule an enzyme needs to work. A prosthetic group stays bound and is not consumed.
competency questionA question the model must be able to answer, written before building. Here they are also the test suite.
conjugate acid / baseTwo species differing by one hydrogen ion, so by charge and formula. Different ChEBI IDs.
DCATW3C vocabulary for describing datasets in a catalogue. DCAT-AP+ is the NFDI extension.
defined classA class with necessary and sufficient conditions, so a reasoner can compute membership rather than being told it.
EC numberFour-level classification of an enzyme activity, not of a protein. Many-to-many with actual proteins.
FAIRFindable, Accessible, Interoperable, Reusable. The research-data principles the whole design answers to.
federationEvaluating part of a SPARQL query against a remote endpoint. A cross-database join over HTTP.
HermiTThe OWL reasoner used here. A Java program Owlready2 runs as a subprocess.
IRIInternationalised Resource Identifier. A URL used as a globally unique key.
JSON-LDRDF serialised as valid JSON. The format that survives a normal web stack.
materialiseWrite computed triples into the stored graph so queries need no reasoner. A materialised view.
microspeciesOne protonation state of a compound. The Unicode normalisation form of chemistry.
n-ary relationA relationship with more than two participants, or with its own attributes. Needs a bridge node in RDF.
NFDI4CatThe German national research-data infrastructure consortium for catalysis. The context for the assignment.
OBO FoundryThe biomedical ontology community and its principles — including FP-005, reuse rather than mint.
open-world assumptionA missing fact is unknown, not false. Why OWL cannot validate.
OWLWeb Ontology Language. Description logic for the semantic web.
Owlready2Python library for authoring OWL and driving a reasoner.
PLPPyridoxal 5′-phosphate. The vitamin-B6-derived prosthetic group of all three enzymes here. CHEBI:597326.
ping-pong bi-biTwo substrates in, two products out, first product leaving before the second substrate binds. Why PLP does not balance.
property pathMulti-hop traversal in one SPARQL pattern, with regex-like operators. + is a recursive CTE.
PROV-OW3C provenance vocabulary — entity, activity, agent.
PURLPersistent URL, run by the curating institution so the identifier outlives the hosting.
RDFResource Description Framework. Graph data as subject-predicate-object triples.
Reac4CatNFDI4Cat’s own reaction ontology, which chose a BFO role pattern rather than n-ary participation.
reasonerA theorem prover that checks consistency, classifies, and computes class membership.
RheaReference database of biochemical reactions. Four IDs per reaction; models them as OWL classes.
SBOSystems Biology Ontology. Supplies the participant-role terms.
SHACLShapes Constraint Language. Closed-world validation for RDF. Your JSON Schema.
SPARQLThe query language and the HTTP protocol for RDF.
stoichiometric coefficientHow many equivalents of a species take part. The value a binary predicate has nowhere to put.
substrate / productWhat goes in / what comes out. Roles in a direction, not types of molecule.
T-BoxThe classes, properties and axioms of an ontology. Schema-shaped, but not enforced.
tautomerSame formula, hydrogen in a different place, interconverting spontaneously. Different ChEBI ID.
transaminaseAn enzyme that moves an amino group between an amino acid and a 2-oxo acid.
QueryPolicyThe read-only contract in api/policy.py — which query forms may be asked of the endpoint, decided rather than inherited from a parser.
GraphRepositoryWhat the service needs of a store, stated in one place. For legibility, not portability — rdflib already ships SPARQLStore.
TurtleThe readable RDF syntax. .ttl.
UniProtProtein database. Also the source of the canonical EC class IRIs.
w3id.orgCommunity-run persistent-identifier redirect service. Namespaces are registered by pull request.
zwitterionA form with both a positive and a negative site, net charge zero. Not the same as the neutral form.

6. If you retain five things

1

Identifiers are global URLs, and that is the whole architecture

Reuse them and a live join against UniProt works. Mint your own and it returns zero rows, with no error.

2

RDF edges carry no properties

So participation needs a bridge node carrying entity, role and coefficient — which is what makes “4 reactions involve L-glutamate, 3 produce it” expressible.

3

Necessary versus sufficient is the difference from a database

Nothing asserts these reactions are transaminations — a reasoner derives it from the participant-role structure, and a control is correctly excluded. Two caveats worth carrying: the definition is a signature, so a reaction where nothing happens would satisfy it; and the shipped control fails on arity, not role.

4

PLP is on the enzyme, not the reaction

It cycles and returns to its starting state, so it does not balance. Modelling it as a substrate would pass every syntactic check and be chemically false.

5

This domain fails green

Wrong identifier, string instead of link, empty defined class, truncated federated join — all return success. Every gate in the project exists because a specific failure is invisible.

And one framing

The requested demo, treated as a miniature FAIR data product. Reusing ChEBI rather than minting, running a reasoner, the validation gates, the federated query — each is a consequence of that sentence rather than an item on a feature list.
